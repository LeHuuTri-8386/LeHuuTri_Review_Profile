⚙ Cài đặt kết nối GitHub
Token chỉ lưu trong trình duyệt của bạn (localStorage), không gửi cho ai khác ngoài GitHub. Tạo tại: GitHub → Settings → Developer settings → Personal access tokens.
Sau khi bấm "Lưu & Xuất bản", GitHub Pages thường mất khoảng 30–90 giây để cập nhật trang chính.
